EDİTÖR ARACI

Yeni yazı oluştur

Formu doldur, Markdown dosyasını indir, GitHub'da _posts klasörüne yükle.

Nasıl yayımlanır?

  1. Formu doldur.
  2. “Markdown dosyasını indir”e bas.
  3. GitHub → telafi → _posts.
  4. Add file → Upload files.
  5. İndirdiğin .md dosyasını yükle.
  6. Commit changes. Yazı otomatik yayımlanır.

HTML ya da CSS değiştirmen gerekmez.
