# TELAFİ

**İhmal edilmiş ne varsa.**

Telafi.org için hazırlanan ilk tek sayfalık statik yayın sitesi.

## Dosyalar

- `index.html` — ana sayfa
- `styles.css` — tüm tasarım ve responsive düzen
- `script.js` — küçük arayüz davranışları
- `CNAME` — GitHub Pages özel alan adı (`telafi.org`)

## GitHub Pages'e yükleme

1. Bu dört dosyayı GitHub'daki `telafi` repository'sinin kök dizinine yükle.
2. Repository içinde **Settings → Pages** bölümüne gir.
3. **Build and deployment → Deploy from a branch** seç.
4. Branch olarak **main**, klasör olarak **/(root)** seç ve kaydet.
5. Domain DNS ayarları yapıldıktan sonra site `telafi.org` üzerinden açılabilir.

## İçerik değiştirme

Örnek yazı başlıkları ve yazar isimleri yalnızca tasarımı göstermek için yer tutucudur. `index.html` içinden doğrudan değiştirilebilir.

## Tasarım yaklaşımı

Tek bir yayını kopyalamadan; gazete disiplini, fikir dergisi tipografisi, güçlü bir masthead ve uzun okuma hissi birleştirildi. İlk sürüm özellikle kategori sayfaları ve karmaşık menüler olmadan tek sayfa tutuldu.
